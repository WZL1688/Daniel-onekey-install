# Meme 观察雷达

ChainPair 1.3 增加独立实现的只读雷达：获取 AVE 的 BNB Chain 或 Solana 榜单，按市场数据初筛，保留观察备注，并提供可选的本地语音提醒。入口位于“行情首页”→“Meme 雷达”，主导航仍为原有五个标签页。

雷达默认关闭，程序重启后也关闭；解锁保险库不会自动开启。它与套利的演示／实盘模式分别控制：即使套利处于演示模式，手动开启雷达后仍会请求真实 AVE 数据。没有 Key 时不会生成模拟代币，也不会假装已经完成扫描。

## 1. 下载、打开与配置

1. 从本项目仓库的 **Code → Download ZIP** 下载源码并解压，安装 [Node.js 24 LTS](https://nodejs.org/) 或更新版本。
2. 在项目目录运行 `npm ci`、`npm start`；Windows 也可双击本项目的 `start.cmd`，macOS／Linux 可运行 `./start.sh`。这些是本项目源码的启动方式，无需安装其他雷达项目的可执行文件。
3. 保留终端窗口，浏览器打开终端打印的完整网址，例如 `http://127.0.0.1:50240/`。实际端口会自动分配，以本次输出为准。仅打开 `http://127.0.0.1/` 会遗漏端口，无法访问该服务。
4. 打开“行情首页”→“Meme 雷达”，展开“AVE Key 与本地语音”。通过 [AVE 官方注册页](https://cloud.ave.ai/register) 创建账户，按照当前账户页面申请数据 API Key。平台名称为 **AVE**，教程中的“EVA”不能作为备用网址依据。
5. 在本机页面输入自己的 AVE Key 和保险库密码，点击“加密保存 Key”。首次建立保险库的密码至少 10 个字符；已有保险库使用相同密码。提交后敏感输入清空，页面和接口只显示配置／锁定状态，不回显 Key。保存本身不请求 AVE，也不验证账户权限。已有保险库若锁定，保存后仍保持锁定，需通过“设置与钱包”显式解锁；不会借保存 Key 解锁交易钱包。
6. 选择本次扫描链和筛选条件，点击“开启只读扫描”。若已进入请求冷却或达到预算，等待页面显示的允许时间后再请求；开启开关不会绕过限制。

AVE Key 与钱包私钥、OKX 凭据共用本机 scrypt + AES-256-GCM 加密保险库，但分别保存、分别使用。雷达不需要连接钱包、导入私钥、OKX 凭据或签名授权。重启后先到“设置与钱包”解锁，再手动开启雷达；无须重新输入已保存的 Key。锁定保险库或更换／移除 Key 会停止自动扫描。不要将 Key、密码或 `data/` 目录上传到仓库或聊天。

## 2. 扫描范围与默认筛选

每次只请求当前选择的一条链，在 AVE 对应链榜单中读取最多 30 个代币。它是**榜单抽样观察**，不扫描全市场，也不承诺发现所有新币。结果在本机每页显示 10 条，翻页不会请求更多 AVE 数据。收藏但已离开最新榜单的记录仍可作为带时间的缓存查看。

| 参数 | 默认值 |
| --- | --- |
| 扫描链 | BNB Chain |
| 自动轮询间隔 | 5 分钟，不能低于 5 分钟 |
| 最低流动性 | 20,000 USD |
| 市值范围 | 50,000–10,000,000 USD |
| 最低 5 分钟成交额 | 5,000 USD |
| 最低持币人数 | 100 |
| 币龄范围 | 30 分钟–168 小时 |
| 最近 1 小时请求预算 | 12 次 |
| 最近 24 小时请求预算 | 144 次 |
| 累计请求预算 | 1,000 次 |

“市场观察”表示价格、流动性、市值、成交额、持币人数、币龄等市场条件初筛通过，仍显示“安全待核验”。所需字段缺失或无效会列入“资料不足”；未达到阈值、行情过期、同链同地址数据冲突或存在已知风险标志会被筛除。程序不会将缺失市值替换为 FDV，也不会把缺失数据当作零费用或安全结论。

卡片分别显示本机采集时间与数据源更新时间。采集或来源数据超过固定 10 分钟会退出市场观察，延长轮询间隔不会延长新鲜度；来源更新时间缺失时列为资料不足，异常时阻止通过初筛。创建时间为零或无法识别时，币龄保持未知。缓存和收藏可在重启后继续查看，但不会因此变成实时行情。

代币身份按链和合约／mint 地址区分。同名、同符号不证明 BNB 与 Solana 资产等价；雷达不会自动写入套利地址、交易池或跨链映射。

## 3. 请求预算、失败与费用

行情请求和手动“查询风险资料”共用同一份**全局至少 5 分钟间隔**及请求预算；切换链、手动刷新、重启、更换或删除 Key 都不会重置。每次派发网络请求前先在 SQLite 中预占并保存一次请求，网络失败、鉴权失败或响应无效也计数。页面刷新及本地翻页只读取本机状态，不占 AVE 请求数。

“最近 1 小时”和“最近 24 小时”是滚动窗口，不在整点或午夜清零；累计数持续保留。默认每天最多 144 次意味着持续每 5 分钟请求也会先触及本机 24 小时预算。可在“筛选与请求预算”中按允许范围修改上限，但更改阈值不会删除历史计数。系统时钟回退时程序会阻止请求，先核对本机时间。

HTTP 429 会保留退避时间，并结合 `Retry-After` 延后请求；401／403 或接口明确返回非成功状态会关闭自动扫描并提示核对账户、接口或套餐。其他失败保留原缓存及冷却，不会密集重试，不会自动换 Key、镜像或绕过限制。

这些数字是本工具的**请求次数限制**，不是 AVE 的 CU 账单或官方免费额度。官方公开文档没有给出本项目可以保证的 CU 费用公式和统一免费配额。开源源码免费不代表第三方 API 永久免费，账户权限、价格和额度以 AVE 当前规则为准。

## 4. 合约风险资料与安全边界

“查询风险资料”只对已扫描／收藏的地址手动读取 AVE 合约报告，会占用一次请求及全局冷却，可能延后下一次行情刷新。当前只识别报告明确给出的貔貅、买入限制、卖出限制、可暂停转账、黑名单方法等正向风险标志；命中后将该代币隔离在筛除结果中。

官方 v2 文档明确说明榜单／代币数据中的 `has_mint_method`、`is_lp_not_locked`、`has_not_renounced`、`has_not_audited`、`has_not_open_source`、`is_in_blacklist`、`is_honeypot`、`ave_risk_level` 已不再使用，应改查合约报告。因此这些旧字段即使全部为 `false`，本工具也不据此判安全。

合约报告没有已识别标志时仍为“安全待核验”，没有“安全通过”状态。负数标记（例如官方样本里的 `is_honeypot: -1`）、不明税率单位、评分、未支持字段以及 Solana 铸币／冻结权限不能被解释成安全。曾经取得的明确风险警示独立保存在本机记录中，不会因退出榜单、取消收藏、重启或后续未知报告而消失。风险警示记录最多 1,000 个地址；达到容量时停止新增风险查询，保留原记录供核对。

“杜绝貔貅”“诈骗盘绝不出现”不能由宣传文字或几项检查证明。报告可能缺失、延迟或不覆盖全部合约行为；通过市场初筛和未检出已知风险，都不能保证可卖出、收益或资产安全。

## 5. 复制、收藏与本地提醒

- **复制 CA**：只复制当前链对应的公开合约／mint 地址。
- **在 AVE 查看**：使用验证后的地址和固定官方域名组成 `https://ave.ai/token/{CA}-{bsc|solana}`，不使用代币简介提供的任意网址，也不添加推荐码。打开外站是独立操作，不授予本工具或外站钱包权限。
- **收藏观察**：最多保存 100 个代币，每条可附最多 1,000 字的本地备注，写入本机 SQLite。过期收藏仍显示时间及筛除原因。
- **本地语音**：默认关闭，需用户明确点击开启，可选中文／英文。仅选用浏览器标识为 `localService: true` 的系统语音，不将代币文字发送到远程语音服务。浏览器需要支持 Web Locks 才启用语音，同一本机地址的多个标签页通过锁及已播记录协调，减少重复播报；缺少本地语言包时提示安装，可继续查看页面。

语音只提醒“新市场观察线索，尚未安全核验”，不会播报买入指令。首次加载、重新开启或切换语音设置时先建立静默基线，不补播历史记录；同链同地址按本地记录去重，记录保留约 7 天、最多 1,000 项。实际语音的 `onstart` 触发后，卡片才移至当前分类列表首位、回到第一页并短时高亮；若用户偏好减少动态效果，则不闪烁。没有实际开始播报时不会伪造“已提醒”。
