# 验证记录

版本：1.3.0。验证日期：2026-11-20。环境：Node.js v24.19.0 / Linux / Chromium。

## 自动测试

`npm test`：158 / 158 通过；`npm run check`：通过。

覆盖顺序交易、确认前置、实际数量传递、单边失败暂停、持久化档案、重启不重播、执行互斥、配置及钱包身份变化并发、累计费用/储备、磨损与60/40再平衡、RPC轮换和主网身份、支持的ABI与实际回执归属。

插件钱包新增测试覆盖：

- 插件不向服务端提供私钥；本机钱包加密、锁定和恢复仍可用。
- 请求归属当前页面、仅交付一次；相同结果可重传，不重复调用钱包发送交易。
- 用户取消、账户/网络切换、心跳过期、结果篡改、过期报价的停止与归档。
- EVM由插件广播一次，哈希返回立即记录，并核对真实RPC交易意图；本机不重复广播。
- Solana签名消息完全一致、Ed25519签名有效、原生币和代币模拟通过后，才由本机记录哈希并广播一次。
- 过期EVM结果仍可保存晚到哈希并要求核对；过期Solana签名不广播。
- 同时连接第二条链不会被第一条链的网络刷新阻塞；旧钱包的延迟余额和报价无法覆盖新状态。

## 验证边界

测试使用本地模拟、固定RPC回执与插件接口替身，没有使用用户私钥、真实OKX账户或真实资金交易。尚未针对用户安装的真实钱包插件、指定代币/交易池/RPC和实际OKX路线完成资金验收。实盘仍受API权限、余额、白名单、支持ABI和路线可用性约束。

## v1.2.0 执行边界与本地复盘

新增独立交易意图校验与参数快照：错误链、代币、精度、数量、收款人、过期/过长报价、未知费用及超出链上整数范围，均在广播前被阻止。每步实际数量绑定确认回执，参数变化中止后续步骤并保存原指纹。指纹用于配置一致性追溯，不是不可篡改存储或外部安全认证。

新增本地复盘与受保护的脱敏导出：按上海完成日期、演示/实盘分别统计；缺失或矛盾记录不计入已核实收益，同样本估算比较单独计数，未知收益不伪装为0。测试验证导出不包含秘密、地址、哈希、原始报价或备忘录中的外部指令。复盘及定时任务只写复盘记录，不调用签名、下单或配置更新。

修复跨链有利成交的利润计算，利润独立于非负磨损指标，估实差异使用同一净收益定义；验证大额跨链正常浮点误差不会误判为费用缺失，明显收支错误仍被拒绝。

`npm run test:review-ui`：通过。六组浏览器流程覆盖复核收益/同样本差异、对应日期与模式的JSON导出、空白时期未验证、过期响应/切页保护、模式隔离、390px布局、文字转义及无执行/配置/签名写请求，零页面/控制台错误。

没有引入外部研究模型、第三方代理安装器、Kelly自动仓位或夜间实盘策略发布。仍未进行真钱交易验收。
