# 安全开发与复盘边界

本项目借鉴结构化输出、独立风控、真实证据和复盘留档的工程方法。新增能力落实在交易意图校验、参数快照及本地复盘中。它们不能证明策略具有正收益，也不能承诺交易或依赖软件绝对安全。

## 已落实的执行边界

- `src/policy.mjs` 根据配置和已确认回执推导预期交易，不接受报价自行指定资产、方向或下一步数量。初始买入前与每一步提交前都检查意图；适配器继续负责支持的 ABI、程序、钱包、主网与回执验证。
- 每笔新交易保存 `policySnapshot` 与 `policyFingerprint`，供核对参数版本。风控由代码执行，研究意见不能覆盖限额、白名单、授权或收款地址。参数快照不是安全认证，旧记录不补造快照。
- 本机加密签名服务和插件签名流程管理私钥。研究或复盘数据中没有私钥、助记词、API 秘密或可调用签名的授权。
- 广播结果不确定、确认超时、回执冲突或单边失败时保留证据并暂停新周期。人工核对不会自动重播、补卖或更换路线。

## 本地复盘的权限

`src/review.mjs` 读取交易档案，生成并保存本机报告。程序运行时在上海时间每日 00:05 后生成前一日报告，启动时到达相同时间条件，也会补齐缺失的前一日报告；页面可按日期重新生成。演示与实盘分开保存。

报告只计算已完成、收支字段完整且金额一致的结果。费用不全的记录不计入已复核收益；估实差异只比较有对应估算的有效样本。没有足够证据时明确显示未验证。美元数据采用稳定币面值和交易归档的原生币参考汇率，外部手动授权、充值等费用需单独核算。

脱敏 JSON 通过字段白名单保留日期、模式、计数、数值汇总及程序生成的固定提示。它不导出钱包地址、哈希、原始报价、RPC、用户备忘录、原始失败文字或凭据。网页、新闻和代币说明中的文字不会被解释成安装、配置或签名指令。用户可自行将该统计文件提供给独立分析工具；本程序不自动发送数据，也没有接入外部研究模型。

复盘建议只用于检查，不能自行改配置、升级实盘代码或提交交易。成交后的统计报告也不是历史时点可直接使用的交易信号，应避免将事后结果混入回测输入。

## Meme 雷达的只读边界（1.3）

雷达是独立实现的市场观察服务，不接入交易状态机或签名器，不按名称推断跨链资产映射，也不向套利设置写入合约、池或方向。参考 [meme-radar 的固定提交](https://github.com/nhovongoc0-max/meme-radar/tree/4b96299462dc4f3fd480c7e632818d989feb07a2) 仅用于评估功能思路，没有复制 AGPL 源码、资源或执行其发布文件。宣传中的“杜绝诈骗／貔貅”不作为功能保证。

AVE 客户端依据 [官方 v2 文档](https://docs.ave.ai/reference/api-reference/v2) 独立编写，只向固定 `https://prod.ave-api.com` 发出榜单／合约报告 GET 请求，使用 `X-API-KEY`，拒绝重定向，限制响应体与等待时间。远端名称、简介、地址、错误和风险报告只作不可信数据；不能触发安装、读取秘密、任意网址请求、配置修改或交易。Key 保存到共用本机加密保险库，不进入普通接口、日志、导出或浏览器持久存储；雷达无需钱包权限。

服务默认关闭，重启、锁库或凭证更改后保持关闭，解锁不等于启动。套利演示模式不能被用作“不会联网”的依据：雷达手动开启后独立读取真实 AVE 数据。所有链、自动／手动榜单和合约报告共用至少 5 分钟间隔及持久请求预算；派发前计数，失败也计数，重启和换 Key 不重置，限流保留退避。默认 12 次／滚动小时、144 次／滚动 24 小时、累计 1,000 次是本机控制，不代表 AVE 免费权益或 CU 计费。

行情缺失不强行补全；需要的数据未知时不通过相应市场筛选。弃用的榜单安全字段不采用，明确合约风险仅用于隔离，缺失、负数哨兵或未检出风险不能判定安全；未知新报告也不清除既有风险。仅采所选链榜单前 30 项，本地分页不能被宣传为全市场风险扫描。

语音必须用户明确启用，只选择 `localService: true` 的系统声音，利用 Web Locks 和本地去重记录协调同源标签页；首次进入不补播历史。真实开始播报才改变列表顺序并高亮，尊重减少动态效果偏好。提醒是未核验的市场观察，不授予交易权限。

实现详情和来源见 [MEME-RADAR.md](MEME-RADAR.md)。受控模拟响应测试不能证明实际 AVE 套餐、计费、可用性或风险覆盖；本次没有真实 Key，且开发网络允许列表限制实际 API 访问，尚未完成真实账户验收。

保存雷达 Key 保留已有保险库的锁定状态，不能间接启用钱包签名。采集与来源时间最多允许 10 分钟新鲜度，未知来源时间不通过初筛；轮询间隔不延长新鲜度。已知风险用独立持久记录保留，榜单轮换或重启不会清除。合约报告若附带其他链或地址则拒绝，AVE 明确拒绝请求时关闭自动扫描。

## 同币机会与库存模式边界（1.4）

同币机会的目录和池扫描只读市场数据。CoinGecko coin ID、名称、符号和 DexScreener 结果都不能自行授予交易资格；候选需明确核验两链准确地址、精度、池和 1:1 映射依据。外部目录地址变化撤销确认，不能自动替换已核验执行参数。人工确认是操作依据，不是代币安全认证。

发现、扫描、报价与交易分别控制。只读扫描首次默认开启，重启延续用户选择；交易默认关闭，只有明确开启已核验清单自动执行后，协调器才可按当前演示／实盘模式和既定限额选择项目。目录读取、候选新增或核验本身均不能开启交易、切换实盘、覆盖金额或调用签名。多币执行绑定独立参数上下文，不能通过反复保存全局配置来移动在途交易的资产目标。

新源客户端固定 CoinGecko、DexScreener 与固定提交的官方 Wormhole 原始映射域名、读取路径和链 allowlist，禁止任意 URL、重定向和远端安装指令，限制响应体与超时。代币描述、映射说明和错误只作不可信数据，不进入执行指令。请求派发前持久占用次数，所有来源共享间隔、每分钟与滚动日预算；失败也计数，429 退避、鉴权和明确拒绝停止。公开接口权限、收费和覆盖能力均不作永久免费或全市场保证。

参考价差只做初筛，未知费用不能填零后标记可执行；两侧价格须来自同轮且不超过固定 120 秒。本机采集时间不能冒充提供方或链上更新时间。只有实际金额双边报价、余额、库存、费用、租金、时效、滑点、冲击、授权及允许交易格式都通过检查，才能执行。

库存模式不调用代币桥接或自动稳定币再平衡；原跨链模式和明确操作的手动跨链保留。高价侧已有目标币是前置条件，买入确认后再次核对由实收量换算的准确卖量。整数向下换算的余数单独归档，拒绝零数量、越界和不明确的资产比率。库存按钱包、链和资产持久预占；不确定或失败记录保留占用，完成或人工核对才释放。

两链成交仍不原子，继续禁止买入未确认时卖出；回执矛盾或单边失败暂停并保留证据，不自动重播、补卖或切换为跨链。库存交易的本轮现金流结果必须同时说明两侧库存变化、精度余数和未包含的补库成本，不包装为库存已配平的闭环利润或稳定盈利。

实现参考 Hummingbot／Gateway 的双侧库存、费用与报价复核思想，独立编写本机协调与执行逻辑，没有为此启动第三方热钱包服务或导入外部安装器。插件签名、加密私钥、OKX ABI、白名单、池校验和经典 SPL Token 的原限制继续生效。完整使用边界见 [INVENTORY-OPPORTUNITIES.md](INVENTORY-OPPORTUNITIES.md)，实际测试记录另见 [TEST-RESULTS.md](TEST-RESULTS.md)；模拟验收不等于真实接口或资金验收。


1.5自动发现可读取随包的官方原资产映射快照，但它不含价格或批准状态；真实池数据缺失不能补造。远端TypeScript只经受限对象数据解析器读取，禁止执行、动态导入或eval。数据来源和Apache许可随包保留。

目录失败与池失败分开保存，只在相应阶段成功后清除；短退避不删除请求计数，不绕过服务端429。CoinGecko DemoKey仅发往固定官方域名请求头，保险库保存维持原锁定状态，接口不回显，页面输入及时清空。只读扫描的自动恢复不能启用交易、批准新资产或解锁钱包。

目录源的RetryAfter按来源持久保存，不能因换Key、重启或界面刷新清除；独立官方目录及池源仍受共享本机预算约束，不因另一个来源的限流无限饥饿。用户取消会终止整个发现/扫描流水线，不接受迟到结果或追加备用源请求。参考价差筛选不要求映射批准，自动交易仍严格要求已核验资产。
