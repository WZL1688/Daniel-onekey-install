ChainPair v1.7.0 完整融合包

Windows：安装 Node.js 24 LTS，然后双击本文件夹中的 start.cmd。
首次启动需要联网安装依赖。请保留命令窗口，打开该窗口显示的完整 http://127.0.0.1:端口/ 地址。
启动窗口与网页顶部应显示 v1.7.0。显示 v1.4.0 时，请关闭旧命令窗口和网页，再运行本文件夹的 start.cmd。

从旧版升级：
1. 先退出旧程序，备份原来的整个 data 文件夹。
2. 将旧 data 完整复制到本文件所在的新文件夹，保留原保险库密码。
3. 从本文件所在的 ChainPair-v1.7.0 文件夹启动，使用新窗口给出的完整地址。
4. 不要上传或发送自己的 data；其中包含钱包、配置、档案和备忘录。

自动扫描：
行情首页 → 同币机会。全新数据默认自动发现并轮询 BNB／Solana 的同币候选，无需先手填 CA。
沿用原数据后如显示扫描关闭，点击“开启自动发现与扫描”。这是只读扫描，自动交易单独开启。
目录候选不是有效收益；必须实际取得两侧池价格，再核验身份、费用、库存和风险。

价格未知／TIMEOUT：
在同币机会页打开“数据源网络／连接检测”，先保存网络方式，再点击“测试行情连接”。
使用代理时填写自己的实际 HTTP／mixed 端口；http://127.0.0.1:7890 只是示例，不能直接当作所有电脑的端口。
分别查看 BNB、Solana 和 CoinGecko 的状态。浏览器能上网不等于行情 API 可达。

已融合：两链行情与机会扫描、MetaMask／OKX／Phantom 插件连接、本机加密钱包、顺序套利与双侧库存模式、
OKX 手动跨链与跨链模式的60/40再平衡、AVE观察雷达、风控、交易档案、复盘和本地备忘录。
默认模拟，未核验的候选不能自动交易。保留 Gas 储备；库存不足或单边结果不确定时停止并人工核对。

macOS／Linux：在本文件夹运行 ./start.sh；也可 npm ci 后 npm start。
完整说明见 README.md 和 docs。程序源码包不含你的 data 或 node_modules。

1.7.0异常处理：极端差价只在观察／未入榜查看，不计算收益，不允许沿用旧报价交易。
首次异常池地址会作为历史证据保留在条目详情；单侧行情缺失或重启不能解除隔离，须新的双侧有效价格复核。

套利看板现直接展示扫描机会：参考价差与可执行报价分别分组，点击“查看并复核”打开准确币种详情。
雷达增加同链多池价格核对；单池仅作参考，冲突池隔离，已核验池不被自动替换。
