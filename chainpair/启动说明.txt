ChainPair v3.0.0 完整融合包

Windows：安装 Node.js 24 LTS，然后双击本文件夹中的 start.cmd。
首次启动需要联网安装依赖。请保留命令窗口，打开该窗口显示的完整 http://127.0.0.1:端口/ 地址。
启动窗口与网页顶部应显示 v3.0.0。显示 v1.4.0 时，请关闭旧命令窗口和网页，再运行本文件夹的 start.cmd。

从旧版升级：
1. 先退出旧程序，备份原来的整个 data 文件夹。
2. 将旧 data 完整复制到本文件所在的新文件夹，保留原保险库密码。
3. 从本文件所在的 ChainPair-v3.0.0 文件夹启动，使用新窗口给出的完整地址。
4. 不要上传或发送自己的 data；其中包含钱包、配置、档案和备忘录。

自动扫描：
行情首页 → 同币机会。全新数据默认自动发现并轮询 BNB／Solana 的同币候选，无需先手填 CA。
沿用原数据后如显示扫描关闭，点击“开启自动发现与扫描”。这是只读扫描，自动交易单独开启。
目录候选不是有效收益；必须实际取得两侧池价格，再核验身份、费用、库存和风险。

价格未知／TIMEOUT：
在同币机会页打开“数据源网络／连接检测”，先保存网络方式，再点击“测试行情连接”。
使用代理时填写自己的实际 HTTP／mixed 端口；http://127.0.0.1:7890 只是示例，不能直接当作所有电脑的端口。
分别查看 BNB、Solana 和 CoinGecko 的状态。浏览器能上网不等于行情 API 可达。

已融合：两链行情与机会扫描、MetaMask／OKX／Phantom 插件连接、本机加密钱包、顺序套利与双侧库存模式、
OKX 手动跨链与跨链模式的60/40再平衡、AVE观察雷达、风控、交易档案、复盘和本地备忘录。
默认模拟，未核验的候选不能自动交易。保留 Gas 储备；库存不足或单边结果不确定时停止并人工核对。

macOS／Linux：在本文件夹运行 ./start.sh；也可 npm ci 后 npm start。
完整说明见 README.md 和 docs。程序源码包不含你的 data 或 node_modules。

3.0.0异常处理：极端差价只在观察／未入榜查看，不计算收益，不允许沿用旧报价交易。
首次异常池地址会作为历史证据保留在条目详情；单侧行情缺失或重启不能解除隔离，须新的双侧有效价格复核。

套利看板现直接展示扫描机会：参考价差与可执行报价分别分组，点击“查看并复核”打开准确币种详情。
雷达增加同链多池价格核对；单池仅作参考，冲突池隔离，已核验池不被自动替换。

3.0.0真实机会复核：套利看板新增真实只读报价与实盘盈利证据。先核验候选映射，在设置导入两链只读地址及配置自己的OKX API并解锁，然后可手动或每60秒自动复核。只读开关不会开启交易，不需要私钥，不签名或广播。压力场景为卖出收入再降0.5%、费用再涨25%，不是成功率或收益保证。
模拟资金和模拟成交均明确标记，不进入实盘成功率。成功按双边确认且扣费后净盈利统计，至少100笔且95%统计区间下限≥70%仅代表历史证据；无样本时显示未验证。库存价差不含未来补库成本。详情见 docs/OPPORTUNITY-QUALITY.md。

3.0.0实盘流程：先选择双侧库存模式、核验同币及两侧库存，配置钱包、OKX和RPC；每链路线可明确选固定池或聚合，官方模板仅填入表单、保存才生效。在套利看板/设置运行实盘预检；额度不足时审阅并明确确认有限BNB授权，费用独立归档，清零后需重新预检和再次审阅。预检与授权不会开启自动套利。
实盘买入前将检查双边未签名模拟；任何一边不通过就不买入。Solana当前路由最小到账指令尚未独立解码，模拟并非未来成交保证。完整使用方法及支持范围见 docs/LIVE-READINESS.md。

V3.0链上研究：行情首页→链上研究可按金额梯度请求BNB/Solana双向真实报价，记录持续/复发和独立paper。需自己的已解锁OKX Web3凭据、只读地址和可用RPC；缺证据不显示假净利润。paper只使用延迟后的真实报价和虚拟资金，20/50U不会放大原实盘1–10U；14天扫描覆盖不是paper验收，不自动实盘。研究数据存data/onchain-research.sqlite，升级同样复制完整data。详见docs/ONCHAIN-RESEARCH-V3.md。
