# ChainPair · 本机双链套利工作台

本地运行的 BNB Chain / Solana 同币套利工具，提供行情、钱包与风控设置、OKX 聚合跨链、交易档案和备忘录五个标签页。默认进入**演示模式**，使用模拟余额和行情，不签名、不广播链上交易。

## V3.0：链上机会研究与独立 paper

新增“行情首页 → 链上研究”：记录BNB／Solana真实同币候选的持续段、复发、双向报价及历史，按1／2／5／10／20／50U金额梯度复核真实兑换数量、费用、执行均价与压力值。未知精度读取链上元数据，未核验同币关系不进入合格机会。20／50U仅供研究和paper，原实盘1–10U限制不变。

paper使用延迟后的新报价和独立SQLite虚拟账本，区分现金价差、费用、库存浮盈亏、净值、回撤和单边敞口；不使用固定DEMO或随机行情证明盈利，不开启签名或实盘。14天进度是参考扫描覆盖，不是paper绩效验收或实盘准入证据，实际长期记录须持续运行积累。完整操作见[链上研究V3说明](docs/ONCHAIN-RESEARCH-V3.md)，代码审计和实施计划见[V3审计](docs/V3-ONCHAIN-AUDIT-PLAN.md)。

## v1.9.0：实盘预检与有限授权

新增实盘预检面板：真实余额、双边报价、库存、费用、授权额度与未签名交易模拟逐项显示。明确区分固定池与OKX聚合路线，提供需用户保存的官方路由模板；BNB支持单独审阅并明确确认本笔有限授权，非零不足额度先单笔清零，费用和回执独立归档。不会因预检、更新或授权自动启动套利。

实盘库存交易在买入前检查两边未签名模拟，任一边未通过就不买入；保留先买入确认、再按实收数量卖库存、失效／单边失败暂停和不重播。当前Solana路由最小到账字段尚未独立解码，报告会提示这一模拟证据边界。支持的路线仍需通过本机API、RPC、白名单和钱包检查。详见[实盘操作与支持范围](docs/LIVE-READINESS.md)。

真实报价复核、压力门槛、模拟／实盘分离和盈利证据统计继续保留。软件测试或预检通过不代表保证盈利或七成成功率；库存现金价差未计未来补库成本。详见[报价复核与盈利证据](docs/OPPORTUNITY-QUALITY.md)。

## 启动

安装 [Node.js 24 LTS](https://nodejs.org/) 或更新版本，解压项目并在目录中运行：

```sh
npm ci
npm start
```

也可在 macOS / Linux 运行 `./start.sh`，Windows 双击 `start.cmd`。启动脚本会在首次运行或升级缺少网络依赖时安装运行依赖。终端会显示类似 `http://127.0.0.1:随机端口` 的本机地址；启动后会请求默认浏览器自动打开完整地址；如果没有自动打开，请复制包含端口号的完整本机地址。仅输入 `http://127.0.0.1/` 会访问默认端口，无法打开本程序。服务只监听 `127.0.0.1`，自动选择空闲端口。设置了 `PORT` 而端口被占用时，会回退到自动选择端口。

首次安装依赖需要网络；安装完成后，演示模式可离线使用。实盘需要可访问所配置的两链 RPC、`web3.okx.com` 与 `api.dexscreener.com`。

## 完整融合包与旧版升级（3.0.0）

下载 `ChainPair-v3.0.0.zip` 后解压，直接使用其中的 `ChainPair-v3.0.0` 文件夹。包内已合并全部页面、后端、钱包、扫描和代理功能，按正常启动流程安装依赖即可运行。

1. 退出旧命令窗口中的程序，关闭旧网页，备份原来的整个 `data`。
2. 需要沿用钱包、配置、档案和备忘录时，在停机状态将原 `data` 完整复制到新文件夹的 `data`。保留保险库密码；浏览器插件钱包重启后重新连接。
3. 双击新文件夹的 `start.cmd`，或在该文件夹运行 `npm ci`、`npm start`。终端显示程序目录和 `ChainPair v3.0.0`。
4. 打开这次终端打印的完整本机地址，页面顶部实际服务版本应为 `v3.0.0`。前后端版本不一致会显示刷新与重新启动提示；不要继续使用旧端口或旧目录的启动脚本。
5. 进入“行情首页 → 同币机会”。原数据保存过停止选择时，点击“开启自动发现与扫描”，恢复只读连续扫描；自动交易另行启用。行情未知时使用三路连接检测核对实际HTTP代理与API权限。

旧截图显示 `v1.4.0`、自动扫描关闭且没有网络检测面板，不能据此判断新版是否联网成功。首次全新数据默认自动发现与扫描，升级仍保留用户已保存的停止选择，不会因为更新开启自动交易。候选地址自动发现不需要手填CA，但真实价格仍取决于API网络与可用交易池。

## Meme 观察雷达（1.3）

在“行情首页”→“Meme 雷达”查看 BNB Chain／Solana 的 AVE 榜单，按流动性、市值、5 分钟成交额、持币人数和币龄初筛，支持本地收藏备注、复制 CA、无推荐码 AVE 跳转及手动开启的中英文系统语音。功能独立实现，没有复制参考雷达项目的 AGPL 源码。

通过 [AVE 官方页面](https://cloud.ave.ai/register) 申请自己的数据 API Key，在雷达页使用本机保险库密码加密保存；不需要连接钱包或提供私钥。默认关闭，重启后需解锁并手动开启；开启后读取真实 AVE 数据，与套利演示／实盘模式独立。每次只取所选链榜单最多 30 项、本地分页，不是全市场扫描；默认所有行情和手动风险查询共用至少 5 分钟间隔及近 1 小时 12 次、近 24 小时 144 次、累计 1,000 次请求预算，失败也计数且重启不清零。这是本机请求数预算，不是第三方 CU 账单或永久免费的承诺。

通过市场初筛仍显示“安全待核验”；查询合约报告发现的明确风险会隔离，未检出不代表安全。雷达不会触发买入或按币名修改套利配置。当前没有用真实 AVE 账户完成接口、权限和计费验收；配置方法、默认阈值、参考仓库固定版本与官方接口来源见 [雷达说明](docs/MEME-RADAR.md)。

## 套利看板与多池价格核对（1.9.0）

“行情首页 → 套利看板”直接展示扫描雷达产生的机会，区分“参考价差达标”和“可执行报价”。前者是正常、同轮且新鲜的公开行情参考；后者还需要当前模式、同币映射、指定1–10U金额、双边报价、完整费用、利润和库存检查通过。钱包或配置切换、报价过期、单侧缺失、读源失败及异常隔离都会使旧报价退出可执行组。点击“查看并复核”会打开雷达中对应币种的核验详情，不改全局代币配置、不自动核验或下单。设置币对的独立执行预览仍保留，并明确模拟数据范围。

雷达对同一代币同一链的多个活跃池做价格窗口核对，默认最大偏离15%，可在高级设置调整。一组相近价格的真实池优先于单个离群大池；同票分歧或没有一致价格时隔离。单池可以作为参考，明确标识尚未交叉验证；不合成平均价格，不把多池一致当作安全认证。已核验池固定，落在异常价格区时隔离而不自动换池；曾发生同链冲突的一侧，后续仅剩单池不会解除隔离，须有新的多池一致结果。

## 异常价格隔离（1.9.0）

参考价格差超过设置上限时，该项目移出默认及候选榜单，保留在“全部观察清单／未入榜”用于核对；停止计算毛差额和收益，不显示推荐套利方向，报价及执行按钮明确灰色禁用。既有正常报价授权不能在行情转为异常后继续复用；后端在复核、提交及买入后继续卖出前重新检查隔离状态。

隔离记录保存在本机，后续单侧行情缺失、缓存消失或重启不会自动解除；只有新一轮双侧有效价格通过检查后才解除，旧授权仍须重新报价。条目存续期间保留首次异常池快照，当前价格恢复或缺失时也可核对首次池地址、记录时间和固定来源链接，历史数据不补填为当前报价；主动移除条目会一并删除对应隔离记录。

条目详情显示当前所选池地址及价格取得方式，区分来源直接提供的目标币USD价格、由baseUSD/priceNative换算和未知来源。对某个异常值归因仍需当时的池与原始报价；仅凭同名、目录关联或截图不能判定仿盘、旧合约、迁移单位或真实收益。

## 山寨币同币双链雷达（1.6）

打开“行情首页”→“同币机会”。雷达默认寻找 **BNB Chain／Solana 两侧都有活跃池的非稳定币候选**，排除稳定币、BTC／ETH／BNB／SOL及已识别的包装、质押表示。AVAX、POL、SUI、APT、PYTH等其他山寨资产仍在范围内，能否入榜取决于真实双侧池，不靠币名推断身份或价格。高级设置可明确包含稳定币或主流资产。

候选由 CoinGecko 统一 coin ID、CoinPaprika 两个平台合约目录的统一资产 ID，以及已收录的发行方公开地址产生；额外保留 Wormhole 官方地址快照。新增目录不依赖 CoinGecko Key，两次平台请求分别计数，并隔离一币多合约／地址复用等歧义。发行方地址快照目前收录 BabyDoge，属于来源事实，不是推荐交易或安全认证。候选自动发现无需手填CA；未被这些来源收录的新币不会被按同名强行配对，不保证全链全市场覆盖。

默认每侧要求：流动性至少20,000美元、24小时成交量至少10,000美元、1小时成交量至少100美元、1小时索引交易至少3笔；同轮采样、两侧采样时差最多30秒、行情采集时间不超过120秒。优先选择符合活跃条件的池；已核验的池仍固定，不能偷偷换成另一池。缺少指标保持未知，超大价差超过默认30%时单列待核对，参考价差达标与真实可执行净收益分别显示。索引成交活跃不等于可卖出、无刷量或无税费，来源未提供精确最后成交时间时不补造。

首页采用紧凑排行，优先展示范围内双侧活跃山寨币，达标价差排在异常值前。可切换“全部观察清单”或“未入榜项目”，查看稳定币、单侧无池、成交不足、陈旧或异常价差的原因。没有合格山寨币时显示空榜，不用稳定币或旧价格补满。只读扫描与交易开关独立，交易仍须人工确认同币数量关系、精度和池后，按1–10U复核真实双边报价、费用、库存与全部风控。

新增“库存模式”：低价链买入确认后，在高价链卖出事先准备的同种代币，单笔不发起代币跨链。高价侧必须已有目标币，低价侧必须有稳定币，两边都须保留 Gas；只有稳定币不能完成这类套利。卖量以买入实际到账换算，精度余数单独归档。库存不足时跳过，不自动跨链补仓；该模式不触发自动稳定币再平衡，手动跨链入口仍保留。

库存成交改变两侧持仓，显示的是扣除本次双方费用和租金后的现金流价差，尚未包含未来补库存、外部授权等成本，不是库存已配平的闭环利润。自动执行仅覆盖已明确核验并启用的清单，继续受原金额、利润、滑点、费用、次数及累计额度限制。配置与使用流程见 [同币机会与库存模式说明](docs/INVENTORY-OPPORTUNITIES.md)。

## 扫描超时与连接检测（1.5.1）

如果候选列表已经出现，但两条链价格均未知，并提示 `TIMEOUT`，说明行情请求超时。浏览器能打开网站不代表 Node 扫描器已经使用同一代理。在“行情首页”→“同币机会”打开“数据源网络与连接检测”：

1. 默认“自动”读取启动进程的 `HTTP_PROXY`／`HTTPS_PROXY` 和 `NO_PROXY`；没有环境代理时，Windows 会检测当前用户启用的本机手动代理。
2. 如果代理没有自动识别，选择“本机 HTTP 代理”，填写代理软件实际启用的 HTTP 或 mixed 地址与端口，例如 `http://127.0.0.1:7890`。此端口只是示例，请以自己的软件为准；SOCKS 端口不能直接填写。
3. 保存后点击只读连接检测，分别查看 BNB 行情、Solana 行情和 CoinGecko 目录。HTTP200但没有符合条件的记录会单列为空，超时、DNS、连接、证书、代理及权限错误分别显示。检测会计入请求预算，最短间隔一分钟，并遵守限流冷却；保存网络设置不会开启交易。

代理只用于同币目录、官方映射与 DexScreener 公开行情；RPC、钱包签名、OKX 和 AVE 仍使用各自原有连接。代理失败不会自动改走直连，不执行 PAC、不扫描本机端口、不关闭证书校验。页面不会回显系统／环境代理地址或凭据。没有代理时可选“直接连接”，但所处网络必须能访问对应 API。

## 交易顺序与限制

默认仍为原来的跨链模式：

```text
低价链买入 → 买入回执确认 → 按实际到账数量跨链
          → 目标链到账回执确认 → 按目标链实际到账数量卖出 → 复核与归档
```

库存模式的顺序为：

```text
低价链买入 → 买入回执确认 → 按实收数量换算高价链卖量
          → 检查并卖出高价链已有库存 → 复核现金流、库存变化与精度余数
```

两种模式均禁止买入未确认时卖出；跨链模式还要求目标链到账确认。超时、单边失败、回执不一致或重启后存在未完成记录时，会暂停新交易并要求人工核对，不自动重播。在途交易不会因为点击暂停而被撤销。

套利单次金额限制为 1–10U，并受利润门槛、滑点、价格冲击、BNB Gas、SOL 网络费、原生币储备、执行次数及累计金额约束。失败或结果不确定的套利尝试也计入额度。报价按模式包括两笔兑换或两笔兑换与同币跨链的成本，小额路线可能因最小额、费用、库存或利润不足而无法执行。

“跨链”页提供 BNB ⇄ Solana 稳定币手动兑换。跨链不设单次、每日金额上限，仍检查余额、美元磨损、磨损率和 Gas 储备。跨链模式中的自动再平衡仅在一侧可用稳定币低于 5U 时触发，目标为不足侧约 60%、来源侧约 40%；使用冷却和重新触发条件，且来源侧再平衡后必须至少保留 5U。库存模式跳过自动再平衡。详情见 [使用说明](docs/USER-GUIDE.md)。

## 交易意图与本地复盘

执行引擎根据所选模式的配置和前一步已确认到账数量，独立核对每笔报价的类型、两链方向、代币地址、精度、准确输入数量、最低到账和有效期，以及实盘发送方与收款钱包。初始买入前检查完整计划；实际到账后重新检查后续报价。库存模式还核对已确认的资产映射与可用库存，多个清单项目使用各自的执行上下文，不靠扫描器反复改写全局代币配置。不能核验的报价会阻止执行，适配器的 ABI、白名单和链上回执检查继续生效。

每笔新交易保存当时的 `policySnapshot` 与 SHA-256 `policyFingerprint`，用于核对风控、资产及估值参数版本。快照排除 RPC 地址、API 凭据和钱包秘密；旧交易没有快照时保留缺失状态，不补造历史参数。指纹用于审计关联，不代表安全审计认证或收益保证。

在“交易档案”的“本地复盘”面板选择日期，可查看发起与完成笔数、已复核净收益、对应估算差异、费用和租金，并导出脱敏 JSON。复盘按 `Asia/Shanghai` 划分日期；程序保持运行时，在每日 00:05 后生成前一日的演示和实盘报告，启动时到达相同时间条件也会补生成缺失的前一日报告。没有完整收支数据的完成记录不计入已复核收益，无可验证记录时显示“未验证”，不会编造零收益。

复盘读取交易档案并保存本地报告，只生成统计与检查建议，不修改风控、发布策略或触发交易。导出不包含钱包地址、交易哈希、原始报价、RPC、用户备忘录或密钥；可由用户自行提供给独立分析工具，本程序不向外部模型发送数据。外部钱包手动授权、充值等未归档费用需另行核对。开发约束与权限边界见 [安全开发说明](docs/SAFE-DEVELOPMENT.md)。

## 钱包连接与实盘

打开“设置与钱包”→“钱包管理”。BNB 钱包卡片可连接 **MetaMask / OKX Wallet**，Solana 钱包卡片可连接 **Phantom / OKX Wallet**。插件须安装、启用并解锁在当前浏览器中；点击相应“连接”按钮后，在插件弹窗允许访问账户。BNB 连接会检查并请求切换到 BNB Chain 主网（56）。本机 `http://127.0.0.1:端口/` 是浏览器可使用插件的回环地址。

连接插件只保存公开地址及插件名称，不需要向程序输入私钥。每笔实盘链上交易仍需在插件中确认，浏览器页面需保持打开；刷新页面或重启程序后重新连接。关闭页面、账户/网络切换或断线会使插件签名不可用并停止触发新交易。演示模式即使连接插件也继续显示模拟余额，不请求真实交易签名。需要无人值守执行时，可使用本机加密私钥钱包。

也可在两链钱包卡片中分别导入私钥或只读地址。私钥和 OKX、AVE、CoinGecko API 凭据通过密码派生密钥，使用 scrypt + AES-256-GCM 加密保存在本机；页面、普通接口与交易档案不回显私钥。重启后数据仍在，保险库默认锁定，需要重新输入密码解锁。只读地址可查余额，不能签名。连接插件时原本机钱包配置会保留，可点击“恢复本机钱包”切回；原私钥仍按保险库锁定状态处理。

插件连接成功后，实盘仍需在本机配置并解锁 OKX API 凭据，以及正确的代币地址、decimals、交易池与审核过的路由 / 程序白名单；跨链模式还需可用的同币跨链路线。当前适配器严格验证 OKX 报价中的配置池地址，路线缺少可验证池信息时会阻止执行。BNB ERC20 必须事先通过外部钱包完成所需 spender 的精确数量授权；本程序不隐式发送授权交易。当前仅支持适配器明确识别的交易格式和经典 SPL Token。

这份项目没有使用用户资金完成真实链上验收。演示结果用于验证流程，不代表真实价格、可成交性或利润。实盘适配条件及来源见 [链上适配说明](docs/LIVE-ADAPTER.md)。

## 数据与备份

默认数据目录为项目内 `data/`：

| 文件 | 内容 |
| --- | --- |
| `archive.sqlite` | 配置、报价、交易与参数快照、状态事件、金额／库存额度占用、备忘录、本地复盘、雷达及同币机会清单／缓存／预算 |
| `vault.json` | 加密私钥、OKX 凭据与 AVE Key |
| `wallets.json` | 钱包公开地址、插件名称、当前模式与原本机钱包配置 |

可通过环境变量 `DUALARB_DATA_DIR` 改用其他绝对路径。停机后备份整个数据目录；SQLite 工作时还可能存在 `-wal`、`-shm` 文件。密码不写入磁盘，遗失密码不能由程序找回。不要将数据目录加入版本控制或分享给他人。

美元核算采用 USDT / USDC 的 1 美元面值，以及配置中的 BNB / SOL 美元参考价格。档案同时保留链上原始数量、Gas、租金与参考汇率，便于自行按实际汇率复算；它不是实时外汇或税务报告。

## 验证与结构

```sh
npm test
npm run check
npm run test:ui
npm run test:wallet-ui
npm run test:review-ui
npm run test:radar-ui
npm run test:opportunities-ui

```

安全和状态机测试使用本地模拟与假回执，不广播真实交易。页面端到端验收方法见使用说明。

```text
public/             中文五标签页面
src/engine.mjs      报价、顺序执行、风控、再平衡与复核
src/policy.mjs      独立交易意图校验、参数快照与指纹
src/review.mjs      本地每日复盘与脱敏导出
src/radar/          只读 AVE 榜单、初筛、合约风险资料与持久请求预算
src/opportunities/  同币候选目录、准确地址池扫描、映射核验及机会记录
src/adapters/       演示、OKX / 链上执行、RPC 轮换
src/vault.mjs       钱包与凭据加密
src/store.mjs       SQLite 档案与备忘录
src/server.mjs      本机 HTTP API、来源校验与 CSRF
src/main.mjs        启动入口
```

如只需要后台服务、不自动打开浏览器，运行 `npm run start:server`。
