# ChainPair · 本机双链套利工作台

本地运行的 BNB Chain / Solana 同币套利工具，提供行情、钱包与风控设置、OKX 聚合跨链、交易档案和备忘录五个标签页。默认进入**演示模式**，使用模拟余额和行情，不签名、不广播链上交易。

## 启动

安装 [Node.js 24 LTS](https://nodejs.org/) 或更新版本，解压项目并在目录中运行：

```sh
npm ci
npm start
```

也可在 macOS / Linux 运行 `./start.sh`，Windows 双击 `start.cmd`。启动脚本会在首次运行时安装运行依赖。终端会显示类似 `http://127.0.0.1:随机端口` 的本机地址；启动后会请求默认浏览器自动打开完整地址；如果没有自动打开，请复制包含端口号的完整本机地址。仅输入 `http://127.0.0.1/` 会访问默认端口，无法打开本程序。服务只监听 `127.0.0.1`，自动选择空闲端口。设置了 `PORT` 而端口被占用时，会回退到自动选择端口。

首次安装依赖需要网络；安装完成后，演示模式可离线使用。实盘需要可访问所配置的两链 RPC、`web3.okx.com` 与 `api.dexscreener.com`。

## Meme 观察雷达（1.3）

在“行情首页”→“Meme 雷达”查看 BNB Chain／Solana 的 AVE 榜单，按流动性、市值、5 分钟成交额、持币人数和币龄初筛，支持本地收藏备注、复制 CA、无推荐码 AVE 跳转及手动开启的中英文系统语音。功能独立实现，没有复制参考雷达项目的 AGPL 源码。

通过 [AVE 官方页面](https://cloud.ave.ai/register) 申请自己的数据 API Key，在雷达页使用本机保险库密码加密保存；不需要连接钱包或提供私钥。默认关闭，重启后需解锁并手动开启；开启后读取真实 AVE 数据，与套利演示／实盘模式独立。每次只取所选链榜单最多 30 项、本地分页，不是全市场扫描；默认所有行情和手动风险查询共用至少 5 分钟间隔及近 1 小时 12 次、近 24 小时 144 次、累计 1,000 次请求预算，失败也计数且重启不清零。这是本机请求数预算，不是第三方 CU 账单或永久免费的承诺。

通过市场初筛仍显示“安全待核验”；查询合约报告发现的明确风险会隔离，未检出不代表安全。雷达不会触发买入或按币名修改套利配置。当前没有用真实 AVE 账户完成接口、权限和计费验收；配置方法、默认阈值、参考仓库固定版本与官方接口来源见 [雷达说明](docs/MEME-RADAR.md)。

## 自动同币机会与库存套利（1.5）

在“行情首页”→“同币机会”发现 BNB Chain／Solana 上的同币价差候选。首次启动自动建立候选并扫描，不需要先手工填写地址。程序优先读取 CoinGecko 同一 coin ID 的多链地址目录，并提供固定来源的 Wormhole 官方映射备用源及32组随包候选快照；再按准确地址查询 DexScreener 交易池。手工添加仅是高级备用。名称、符号或看起来相同的代币图标不作为同币依据。目录是元数据关联，不能证明两链表示始终 1:1、可赎回或安全，执行前需要使用者核实合约、精度、池及映射依据。

发现、扫描和交易分别控制。只读扫描首次默认开启，重启延续用户的扫描选择；新目录项目不会自动获得交易资格，自动交易仍须单独开启。参考价差不含完整费用，只有按设置的 1–10U 金额完成双边报价、库存和风控复核后，才允许执行。公开 API 可能要求账户、限制额度或暂时不可用；目录暂时不可用时自动使用带日期的官方映射候选并显示具体连接状态和重试时间；不会填造价格、余额或交易，也不承诺全链全市场覆盖。CoinGecko要求权限时可在“数据源连接”加密保存自己的Demo Key。

新增“库存模式”：低价链买入确认后，在高价链卖出事先准备的同种代币，单笔不发起代币跨链。高价侧必须已有目标币，低价侧必须有稳定币，两边都须保留 Gas；只有稳定币不能完成这类套利。卖量以买入实际到账换算，精度余数单独归档。库存不足时跳过，不自动跨链补仓；该模式不触发自动稳定币再平衡，手动跨链入口仍保留。

库存成交改变两侧持仓，显示的是扣除本次双方费用和租金后的现金流价差，尚未包含未来补库存、外部授权等成本，不是库存已配平的闭环利润。自动执行仅覆盖已明确核验并启用的清单，继续受原金额、利润、滑点、费用、次数及累计额度限制。配置与使用流程见 [同币机会与库存模式说明](docs/INVENTORY-OPPORTUNITIES.md)。

## 交易顺序与限制

默认仍为原来的跨链模式：

```text
低价链买入 → 买入回执确认 → 按实际到账数量跨链
          → 目标链到账回执确认 → 按目标链实际到账数量卖出 → 复核与归档
```

库存模式的顺序为：

```text
低价链买入 → 买入回执确认 → 按实收数量换算高价链卖量
          → 检查并卖出高价链已有库存 → 复核现金流、库存变化与精度余数
```

两种模式均禁止买入未确认时卖出；跨链模式还要求目标链到账确认。超时、单边失败、回执不一致或重启后存在未完成记录时，会暂停新交易并要求人工核对，不自动重播。在途交易不会因为点击暂停而被撤销。

套利单次金额限制为 1–10U，并受利润门槛、滑点、价格冲击、BNB Gas、SOL 网络费、原生币储备、执行次数及累计金额约束。失败或结果不确定的套利尝试也计入额度。报价按模式包括两笔兑换或两笔兑换与同币跨链的成本，小额路线可能因最小额、费用、库存或利润不足而无法执行。

“跨链”页提供 BNB ⇄ Solana 稳定币手动兑换。跨链不设单次、每日金额上限，仍检查余额、美元磨损、磨损率和 Gas 储备。跨链模式中的自动再平衡仅在一侧可用稳定币低于 5U 时触发，目标为不足侧约 60%、来源侧约 40%；使用冷却和重新触发条件，且来源侧再平衡后必须至少保留 5U。库存模式跳过自动再平衡。详情见 [使用说明](docs/USER-GUIDE.md)。

## 交易意图与本地复盘

执行引擎根据所选模式的配置和前一步已确认到账数量，独立核对每笔报价的类型、两链方向、代币地址、精度、准确输入数量、最低到账和有效期，以及实盘发送方与收款钱包。初始买入前检查完整计划；实际到账后重新检查后续报价。库存模式还核对已确认的资产映射与可用库存，多个清单项目使用各自的执行上下文，不靠扫描器反复改写全局代币配置。不能核验的报价会阻止执行，适配器的 ABI、白名单和链上回执检查继续生效。

每笔新交易保存当时的 `policySnapshot` 与 SHA-256 `policyFingerprint`，用于核对风控、资产及估值参数版本。快照排除 RPC 地址、API 凭据和钱包秘密；旧交易没有快照时保留缺失状态，不补造历史参数。指纹用于审计关联，不代表安全审计认证或收益保证。

在“交易档案”的“本地复盘”面板选择日期，可查看发起与完成笔数、已复核净收益、对应估算差异、费用和租金，并导出脱敏 JSON。复盘按 `Asia/Shanghai` 划分日期；程序保持运行时，在每日 00:05 后生成前一日的演示和实盘报告，启动时到达相同时间条件也会补生成缺失的前一日报告。没有完整收支数据的完成记录不计入已复核收益，无可验证记录时显示“未验证”，不会编造零收益。

复盘读取交易档案并保存本地报告，只生成统计与检查建议，不修改风控、发布策略或触发交易。导出不包含钱包地址、交易哈希、原始报价、RPC、用户备忘录或密钥；可由用户自行提供给独立分析工具，本程序不向外部模型发送数据。外部钱包手动授权、充值等未归档费用需另行核对。开发约束与权限边界见 [安全开发说明](docs/SAFE-DEVELOPMENT.md)。

## 钱包连接与实盘

打开“设置与钱包”→“钱包管理”。BNB 钱包卡片可连接 **MetaMask / OKX Wallet**，Solana 钱包卡片可连接 **Phantom / OKX Wallet**。插件须安装、启用并解锁在当前浏览器中；点击相应“连接”按钮后，在插件弹窗允许访问账户。BNB 连接会检查并请求切换到 BNB Chain 主网（56）。本机 `http://127.0.0.1:端口/` 是浏览器可使用插件的回环地址。

连接插件只保存公开地址及插件名称，不需要向程序输入私钥。每笔实盘链上交易仍需在插件中确认，浏览器页面需保持打开；刷新页面或重启程序后重新连接。关闭页面、账户/网络切换或断线会使插件签名不可用并停止触发新交易。演示模式即使连接插件也继续显示模拟余额，不请求真实交易签名。需要无人值守执行时，可使用本机加密私钥钱包。

也可在两链钱包卡片中分别导入私钥或只读地址。私钥和 OKX、AVE、CoinGecko API 凭据通过密码派生密钥，使用 scrypt + AES-256-GCM 加密保存在本机；页面、普通接口与交易档案不回显私钥。重启后数据仍在，保险库默认锁定，需要重新输入密码解锁。只读地址可查余额，不能签名。连接插件时原本机钱包配置会保留，可点击“恢复本机钱包”切回；原私钥仍按保险库锁定状态处理。

插件连接成功后，实盘仍需在本机配置并解锁 OKX API 凭据，以及正确的代币地址、decimals、交易池与审核过的路由 / 程序白名单；跨链模式还需可用的同币跨链路线。当前适配器严格验证 OKX 报价中的配置池地址，路线缺少可验证池信息时会阻止执行。BNB ERC20 必须事先通过外部钱包完成所需 spender 的精确数量授权；本程序不隐式发送授权交易。当前仅支持适配器明确识别的交易格式和经典 SPL Token。

这份项目没有使用用户资金完成真实链上验收。演示结果用于验证流程，不代表真实价格、可成交性或利润。实盘适配条件及来源见 [链上适配说明](docs/LIVE-ADAPTER.md)。

## 数据与备份

默认数据目录为项目内 `data/`：

| 文件 | 内容 |
| --- | --- |
| `archive.sqlite` | 配置、报价、交易与参数快照、状态事件、金额／库存额度占用、备忘录、本地复盘、雷达及同币机会清单／缓存／预算 |
| `vault.json` | 加密私钥、OKX 凭据与 AVE Key |
| `wallets.json` | 钱包公开地址、插件名称、当前模式与原本机钱包配置 |

可通过环境变量 `DUALARB_DATA_DIR` 改用其他绝对路径。停机后备份整个数据目录；SQLite 工作时还可能存在 `-wal`、`-shm` 文件。密码不写入磁盘，遗失密码不能由程序找回。不要将数据目录加入版本控制或分享给他人。

美元核算采用 USDT / USDC 的 1 美元面值，以及配置中的 BNB / SOL 美元参考价格。档案同时保留链上原始数量、Gas、租金与参考汇率，便于自行按实际汇率复算；它不是实时外汇或税务报告。

```text
public/             中文五标签页面
src/engine.mjs      报价、顺序执行、风控、再平衡与复核
src/policy.mjs      独立交易意图校验、参数快照与指纹
src/review.mjs      本地每日复盘与脱敏导出

src/opportunities/  同币候选目录、准确地址池扫描、映射核验及机会记录
src/adapters/       演示、OKX / 链上执行、RPC 轮换
src/vault.mjs       钱包与凭据加密
src/store.mjs       SQLite 档案与备忘录
src/server.mjs      本机 HTTP API、来源校验与 CSRF
src/main.mjs        启动入口
```

如只需要后台服务、不自动打开浏览器，运行 `npm run start:server`。
