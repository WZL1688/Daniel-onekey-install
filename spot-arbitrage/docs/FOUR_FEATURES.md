# 成本、流动性、资金配额与风险熔断

本次增强针对现货工具。它没有新增永续、资金费、积分估值、自动成交查询或自动平仓。所有正式提交继续走最新规则、余额、订单、价格和盘口复核；实盘默认关闭，原有接入验证锁及未知订单阻塞保持有效。

## 默认配置和升级

旧状态会补充四组配置，不删除 Key、历史批次、限速或安全阻塞。再平衡预估默认0，新增流动性限制默认不启用，资金配额默认关闭，每日亏损限额默认未配置。确认配置后才改变对应筛选行为。

首次启动新版之前应正常停止旧服务并备份完整 data 目录，包含主密钥。不要并行启动两个实例，也不要将 data、.env 或密钥放进分享包。

## 成本比较

在设置页按报价币添加库存再平衡预估成本。例如 USDT 的估计不用于 USDC 交易对。这是普通套利每批的固定预估，用于机会比较，不是已经支付的费用。

- 深度净利润：深度卖出金额减去深度买入金额、双边手续费、固定缓冲和本批再平衡预估。
- 限价保守净利润：按最终买卖限价计算双边含费金额，再扣固定缓冲及再平衡预估。
- 净收益率 bps：限价保守净利润 ÷ 买侧保守含费支出 × 10000。100 bps = 1%。这是买侧成本口径，不是年化或两所总资金回报。
- 机会详情分别展示执行净利润（未扣再平衡预估）、再平衡预估和费用合计。已纳入固定缓冲的同一项成本不要再次填进预估。

再平衡预估不会自动从人工填写的实际净收益再次扣除。动态平衡继续使用原有每笔最大亏损规则，普通套利的再平衡估计和最低 bps 门槛不降低或替换它。

## 流动性筛选

设置页支持以下限制，资金复核和实际提交仍会使用新盘口重新计算：

| 设置 | 含义 |
| --- | --- |
| 最低净收益率 | 普通套利的附加门槛，原有深度利润和限价利润门槛仍必须同时通过。 |
| 最大所内价差 | 分别限制每所 `(卖一－买一) ÷ 中间价`，不是限制两所之间可获利的价差。 |
| 最小有效深度金额 | 两侧最终限价范围内的返回盘口金额分别达标；限价外的巨大挂单不算有效流动性。单位是该交易对的报价币。 |
| 最大盘口接收时差 | 两份盘口的本地接收时间差；它不能证明交易所源头报价完全同步。原有盘口年龄上限仍有效。 |

空的可选上限表示不限制，显式0表示零容忍。例如最大接收时差0只允许相同接收时刻。页面显示的完整盘口仍只是本次 REST 返回范围，不能证明额外深度存在。

## 资金配额

勾选“启用资金配额”后，按交易所和资产设置：

- 预留库存：该资产可用余额中保留不用的数量。
- 单笔支出上限：本批向外支付的该资产上限。买侧为报价币含费支出，卖侧为基础币数量及潜在基础币手续费。
- 买入后持仓上限：仅在该资产作为买入基础币时，限制当前总余额加本笔买入数量；不会假设另一腿已成交来提前腾出额度。

数量的单位跟随资产，不能把 BTC 数量与 USDT 金额相加。未配置资产不附加自定义上限，但始终受实际可用余额约束；上限留空表示不附加限制，显式0禁止对应支出或买入。预留0表示不额外预留。

最终复核取买侧报价币额度、卖侧基础币额度和买入持仓余量，再与默认金额、库存平衡差额等取最严约束。按共同步长取整后，重新穿透两侧深度，重新计算价格、费用及利润。买侧额度按最终最差限价和手续费计算，不能只用买一或平均价格估算可买数量。

例如合成盘口买价100、卖价102、双方费率0.1%、数量步长0.01时，买侧资金上限50.05最多支持数量0.50；不能沿用原数量1.00的利润。若缩量后达不到最小订单或利润门槛，直接拒绝，不发送订单。

轮询中的配额预览使用缓存余额，不增加私人 API 请求。缓存缺失或过期时只能显示待资金复核的市场机会；正式提交强制刷新。配额不是交易所资金冻结，无法限制其他程序或人工在同一账户的操作。批次保存配额复核快照；未核对批次仍阻塞所有后续批次。

## 已核对亏损熔断

在设置页按报价币配置每日已核对亏损限额。账本使用 Asia/Shanghai 自然日，以人工核对完成时间入账；不按提交时间回填，也不把尚未核对的预计盈亏当成实际结果。

- 只累计 RESOLVED 批次中实际净收益为负的部分，盈利不抵扣亏损预算。同一批次只计入一次。
- USDT、USDC 等分别累计，不进行隐含兑换或合并。
- 达到任一配置限额即持久化熔断，停止新单；限额0只在出现实际亏损后触发，不因零亏损立即熔断。
- 熔断同时阻止普通套利、动态平衡及手动提交。它不自动平仓、不补单、不重发订单。
- 重启、跨日、提高或删除限额都不会自动解除已有熔断。

例如同一核对日依次确认 -1、+3、-1 USDT，累计亏损为2 USDT而非0。若限额为2，则熔断。由于损益依赖人工核对，该功能不能保证亏损在到达限额之前实时停止，也不能保证损失绝不超限。

“人工复位风险熔断”要求实盘关闭、没有执行中或未核对批次，并输入完整确认文字。当天累计亏损仍达到当前限额时拒绝复位；应等待新日或明确修改限额后再复位。复位保留台账和历史，不会自动重新开启实盘。

## 修改与删除配置

设置页可删除成本、亏损限额和配额行。后台采用逐项补丁，其他币种和交易所配置不会被空表单误清除。API 中对应的映射项传 null 才表示删除；资产内 maxOrder/maxHolding 的 null 则表示该上限不限制。删除亏损限额不能代替人工复位。
